# 🏛️ Sistema de Deputados

Sistema web desenvolvido em React para consultar informações dos Deputados Federais do Brasil utilizando a API oficial de Dados Abertos da Câmara dos Deputados.

## 📌 Sobre o projeto

O sistema permite consultar os Deputados Federais e visualizar informações como nome, partido, estado, foto e dados do gabinete.

Também é possível pesquisar deputados, aplicar filtros e salvar deputados favoritos.

## 🚀 Funcionalidades

- 📋 Listagem dos Deputados Federais
- 🔎 Busca por nome
- 🗺️ Filtro por estado
- 🏛️ Filtro por partido
- 📸 Foto dos deputados
- 📄 Visualização de detalhes
- 🏢 Informações do gabinete
- 📧 E-mail do gabinete
- ☎️ Telefone do gabinete
- ⭐ Sistema de favoritos
- 💾 Salvamento dos favoritos no navegador
- ⭐ Filtro para visualizar somente os favoritos
- 📱 Layout responsivo

## 🛠️ Tecnologias utilizadas

- React
- JavaScript
- Vite
- Axios
- HTML
- CSS
- API REST
- LocalStorage

## 🌐 API utilizada

Os dados dos deputados são obtidos através da API oficial de Dados Abertos da Câmara dos Deputados.

API:

https://dadosabertos.camara.leg.br/api/v2
